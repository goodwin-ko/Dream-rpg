# DREAM RPG 아이템 조합기 & 파밍 도우미

사용자가 제공한 `dream01.xlsx` 엑셀 파일의 프리스트 탭과 보스 탭을 기반으로 구축된 반응형 웹 애플리케이션입니다.

---

## 🚀 실행 방법 (2가지 중 선택)

### 방법 1. 원클릭 실행 (가장 추천)
* `run_web.bat` 파일을 **더블클릭**합니다.
* 자동으로 로컬 웹 서버가 실행되고, 기본 웹 브라우저에 `http://localhost:8088` 화면이 즉시 열립니다.

### 방법 2. 브라우저로 직접 열기
* `index.html` 파일을 **더블클릭**하여 크롬(Chrome), 엣지(Edge), 웨일(Whale) 등 브라우저로 엽니다.
* 별도 서버 설치 없이도 100% 정상 작동합니다.

---

## 🌟 주요 기능 안내

### 1. 6개 부위별 아이템 조합 트리 & 체크리스트
* **부위별 최종 아이템**:
  * ⚔️ **무기**: `태초의 여명` (성스러운 홀 $\rightarrow$ 타오르는 심판의 홀 $\rightarrow$ 타오르는 별 마법봉 $\rightarrow$ 태초의 여명)
  * 🛡️ **갑옷**: `신휘-성스러운 치유 로브` (고대 수호자의 의복 $\rightarrow$ 생명의 기적-자연의 선물 $\rightarrow$ 신휘)
  * 👑 **투구**: `별신의 왕관` (별의 왕관 $\rightarrow$ 프로토스 왕관 $\rightarrow$ 별신의 왕관)
  * 💍 **장신구**: `영원의 모래시계` (시공 질서의 반지 + 속세의 빛-만가의 등불)
  * 📜 **보조장비**: `성주의 정화록` (영광의 주문서 $\rightarrow$ 보도-지고의 영광경 $\rightarrow$ 성주의 정화록)
  * 💎 **마나석**: `각인-별의 축복` (천상의 수호석 + 고대 해양의 기억)
* **2가지 보기 모드 지원**:
  * **계층형 트리 뷰**: 상위 템 아래로 하위 재료들이 나뭇가지 형태로 연결된 구조
  * **단계별 조합 뷰**: 1단계 기초 조합 $\rightarrow$ 2단계 $\rightarrow$ 3단계 $\rightarrow$ 최종 완성까지 순차적으로 진행하는 플로우
* **체크리스트 & 자동 저장**:
  * 내가 획득한 보스 재료를 체크(✓)하면 상단 달성률(%)이 실시간 갱신됩니다.
  * 체크 상태는 브라우저(로컬 스토리지)에 자동 저장되므로 브라우저를 닫았다가 다시 열어도 그대로 유지됩니다.
  * 하단에 **"현재 필요한 잔여 재료 목록"**이 실시간 집계되어 무엇을 더 구해야 하는지 한눈에 보입니다.

### 2. 🎯 보스별 파밍 경로 리포트
* 현재 부족한 재료들을 **보스 이름 및 요구 레벨 순서(Lv.1 ~ Lv.400)**로 모아서 보여줍니다.
* 예: `별의 정령 알갈론 (Lv.340)`을 잡으면 현재 몇 개의 재료(은하의 모래, 별의 파편 등)를 동시에 캘 수 있는지 바로 확인 가능합니다.
* 이 탭에서도 체크박스를 직접 체크하여 파밍 완료 처리가 가능합니다.

### 3. 📖 보스 드랍 도감
* 엑셀 '보스' 탭에 기재된 **34종의 모든 보스와 210개 드랍 아이템**을 검색할 수 있습니다.
* 레벨 구간별 필터(Lv.160~260, 280~320, 340, 360, 380~400) 제공
* 현재 선택된 직업에서 조합 재료로 쓰이는 아이템에는 **`★ 프리스트 재료`** 골드 뱃지가 자동 표시됩니다.

## 📁 추후 다른 직업 탭 추가 시 업데이트 방법

게임 내 총 31개 직업 중 다른 직업 탭을 추가했을 때는 아래 2가지 중 편한 방법으로 적용할 수 있습니다:

1. **웹 화면에서 바로 올리기**:
   * 웹 브라우저 우측 상단의 **[📁 엑셀 파일 열기]** 버튼을 누르고 새 엑셀 파일을 드래그 & 드롭하면 브라우저가 즉시 인식하여 새 직업이 활성화됩니다.
2. **폴더 내 파일 교체 후 파싱**:
   * 새 엑셀 파일을 `d:\code\Dream\dream01.xlsx` 위치에 덮어쓴 뒤 터미널에서 `python tools/parse_excel.py`를 실행합니다.
